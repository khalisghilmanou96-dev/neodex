# NeoDex ☄️ — NASA NeoWs

Suivi des astéroïdes proches de la Terre avec NASA NeoWs.

Fonctions :
- aujourd'hui ou plage jusqu'à 7 jours ;
- liste des objets géocroiseurs ;
- diamètre estimé ;
- vitesse relative ;
- distance à la Terre et distance lunaire ;
- indicateur `is_potentially_hazardous_asteroid` ;
- compteur d'objets et objet le plus proche ;
- frontend GitHub Pages sans installation.

Le site utilise `DEMO_KEY`, la clé de démonstration publique de NASA Open APIs. Elle convient à un usage léger et reste soumise aux limites NASA.
